# 22. The `[Reactive]` attribute and the source generator

`[Reactive]` (`ReactiveAttribute`) marks two kinds of member.

- On a **parameterless void instance method**, `Reactor.AddReactiveMethods` adds that method as a reaction.
- On a **partial property** with empty `get` and `set` (or `init`) accessors, the Fluorine source generator writes a `Register<T>` and the accessors, and marks the property `[AutoNotify]`.

The attribute itself is an empty marker:

```csharp
[AttributeUsage(AttributeTargets.Property | AttributeTargets.Method, Inherited = false, AllowMultiple = false)]
public sealed class ReactiveAttribute : Attribute
{
}
```

## Methods: `AddReactiveMethods`

```csharp
public void AddReactiveMethods(object instance)
```

The call walks the instance type and its bases. Each matching method becomes one named reaction; the reaction name is the method name. The first run is queued, so it happens after `AddReactiveMethods` returns.

```csharp
class Watcher
{
    public readonly Register<int> Count = new Register<int>(0);

    [Reactive]
    public void Report()
    {
        Console.WriteLine(Count.Value);
    }
}

var watcher = new Watcher();
reactor.AddReactiveMethods(watcher);
```

What is added:

- instance methods only, public or non-public;
- return type `void`, no parameters;
- marked `[Reactive]` on the declaration that introduces them.

A virtual method is one reaction; the override on the instance runs, even when the override itself is not marked. A method declared with `new` is a separate reaction, and is added only if it is marked. An abstract marked method runs its most derived concrete override.

Methods with parameters, a non-void return, generic parameters, or no `[Reactive]` attribute are left alone.

A null `instance` throws `ReactiveException`. A disposed reactor adds nothing, as `Add` does. When the method throws, the exception reaches the reaction as the method threw it; it is not wrapped in `TargetInvocationException`.

`AutoNotify()` calls `AddReactiveMethods(this)` from its constructor, so a model that derives from `AutoNotify` needs no extra call for its own marked methods. Those method reactions are armed immediately. The `[AutoNotify]` property reactions stay lazy until `PropertyChanged` has a subscriber ([AutoNotify](autonotify.md)).

Any reactor can scan any object. The object does not have to derive from `AutoNotify` or `Reactor`.

## Properties: the source generator

Partial properties need a recent C# language version. The generator tests and the PersonEditor demo use `<LangVersion>13</LangVersion>`. Writing registers by hand also works with `AutoNotify`.

Add the generator as an analyzer next to the Fluorine project reference:

```xml
<PropertyGroup>
  <LangVersion>13</LangVersion>
</PropertyGroup>
<ItemGroup>
  <ProjectReference Include="..\..\src\Fluorine\Fluorine.csproj" />
  <ProjectReference Include="..\..\src\Fluorine.Generators\Fluorine.Generators.csproj"
                    OutputItemType="Analyzer"
                    ReferenceOutputAssembly="false" />
</ItemGroup>
```

`OutputItemType="Analyzer"` is what runs the generator during compilation. The generator tests also set `ReferenceOutputAssembly="true"` so they can construct `ReactivePropertyGenerator` themselves; an application does not need that.

The generator project (`src/Fluorine.Generators/Fluorine.Generators.csproj`) targets `netstandard2.0` and is a Roslyn incremental generator (`ReactivePropertyGenerator`).

### What you write, and what is generated

You write a partial type and a partial property:

```csharp
namespace App
{
    public partial class Household : AutoNotify
    {
        public Household()
        {
            HappyHousewife = 7;
        }

        [Reactive]
        public partial int HappyHousewife { get; set; }

        [Reactive]
        public partial string Title { get; set; }

        [AutoNotify]
        public int Twice => HappyHousewife * 2;
    }
}
```

The generator emits a companion file (hint name `Fluorine.Reactive.<Type>.g.cs`) along these lines:

```csharp
// <auto-generated/>
#pragma warning disable
namespace App
{
    partial class Household
    {
        global::Fluorine.Register<int> happyHousewife = new global::Fluorine.Register<int>();

        [global::Fluorine.AutoNotify]
        public partial int HappyHousewife
        {
            get => happyHousewife.Value;
            set => happyHousewife.Value = value;
        }

        global::Fluorine.Register<string> title = new global::Fluorine.Register<string>();

        [global::Fluorine.AutoNotify]
        public partial string Title
        {
            get => title.Value;
            set => title.Value = value;
        }
    }
}
```

Reading or writing the property is reading or writing the register. The generated `[AutoNotify]` is what `AutoNotify` watches. `Twice` already has a body, so the generator leaves it alone; its `[AutoNotify]` is enough for the notification reaction to read `HappyHousewife`.

The generated register is created with `new Register<T>()`. Assign an initial value in the constructor, as `HappyHousewife = 7` does above.

`[AutoNotify]` on a partial `get`/`set` property also produces a register. The generator does not add a second `[AutoNotify]` in that case, because the attribute is already on the property:

```csharp
public partial class Counter : AutoNotify
{
    [AutoNotify]
    public partial int Count { get; set; }
}
```

Accessor modifiers are preserved (`private set`, `init`). The type may be a partial class, record or struct, including nested generic types. The backing field is the camel-cased property name (`happyHousewife`). If that name is already taken, the generator tries `_<name>`, then numbered suffixes. A C# keyword such as `class` becomes `@class`.

### Diagnostics

A `[Reactive]` property that the generator cannot fill in is reported as an error:

| Id | When |
|---|---|
| `FLUORINE001` | the property is not `partial` |
| `FLUORINE002` | its type is not a partial class, record or struct |
| `FLUORINE003` | it is not an ordinary instance property with empty `get` and `set` (or `init`) accessors |
| `FLUORINE004` | it is static |

`[AutoNotify]` properties that are not partial auto-properties are ignored by the generator rather than reported. They are handled at run time by `AutoNotify`, as `Twice` is.
